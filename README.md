# Risk Hub

A browser lab for market-risk and quant methods (VaR/ES, GARCH, copulas, options, XVA, credit, ML), all calculated in vanilla JavaScript with no server. Educational, non-commercial portfolio project.

- Crypto daily prices: [Binance Vision](https://data.binance.vision), CC BY-NC-SA 4.0 (not affiliated with Binance). See `data/ATTRIBUTION.txt`.
- Option chains and the DVOL index are fetched live from the Deribit public API by your own browser; nothing from Deribit is stored here.
- Rates and FX: ECB, US Treasury, NY Fed.

Not investment advice.

## Python code

Every module has a standalone Python script in [`python/`](python/INDEX.md) (also behind the "Python" button in the app).
